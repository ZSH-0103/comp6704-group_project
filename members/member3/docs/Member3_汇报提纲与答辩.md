# Member 3 展示提纲（约7–8分钟）

这份材料用于理解和制作自己的slides，不是全组30分钟slides，也不是完整四人结论。报告和图上的每个数字都可追溯到CSV。

## 1. 研究问题（约45秒）

一句话：“同一个随机梯度既影响更新方向，又影响分母，会不会让归一化更新产生偏差？”

解释我们的算法对：RMSProp与ADOPT的β₁=0设置。这样聚焦二阶矩归一化，而不是把动量因素混进来。说明小数据集也可以检验明确的优化机制。

## 2. 两个更新规则（约1分15秒）

展示 `report/sections/section2_methodology_member3.tex` 的两个公式。

- RMSProp：先把当前g²放进v，再用v归一化当前g。
- ADOPT-0：先用旧v归一化当前g，最后才把g²放进v。
- 实现细节不能藏：不同epsilon位置、第一梯度初始化、裁剪t^1/4；300梯度调用vs299参数更新。
- 理论条件是下有界、光滑、无偏梯度、二阶矩一致有界；不是“任何学习率、任何网络必然更好”。

## 3. 公平实验设置（约1分钟）

三个任务：Fashion+MLP、CIFAR+小CNN、Tiny Shakespeare+GRU。沿用Member 4数据/模型、CPU4线程、相同配对初始化和批次，main300调用、seeds1/2/3。每方法3个LR候选，seed11、100步按验证CE选择；test不调参。

主动交代一个关键限制：文本只评估每个区间前1024个重叠窗口，这是沿用共享代码默认值；我们的结论不代表整个文本测试集。

## 4. 主实验结果（约1分30秒）

展示 `results/member3/figures/member3_overview.pdf` 或主表，不在一页塞全部原始日志。

- Fashion：81.17% vs79.43%，RMSProp在本设置更好。
- CIFAR：47.47% vs47.33%，差异很小，不能夸大。
- Text CE：2.028 vs2.086，越低越好；RMSProp更好。
- 误差带/表格±是样本SD，3种子，不是95%置信区间。
- 不说“新算法没用”，下一页解释机制条件。

## 5. 机制诊断与消融（约1分45秒）

展示 `results/member3/figures/member3_diagnostic.pdf`。

目标logcoshθ，θ可以取任意实数，最优θ=0。噪声-1概率.9、+9概率.1，均值0、方差9；这比单纯换更难数据集更容易隔离问题。

β₂=.9时，RMSProp平均θ停留在正方向约.448，ADOPT约-.008；最后1000次调用gap .1094 vs.0135。Current-moment matched-clip沿用ADOPT初始化和裁剪，却保留偏移；去裁剪ADOPT也表现好。因此本实验支持归一化时序的作用。

β₂=.999时差距很小；主神经实验也用了.999。机制实验有效不意味着短预算网络一定受益。这里讨论有限时间轨迹，不把它说成不收敛证明。

## 6. 结论、成本与边界（约45秒）

相同O(d)额外状态；测得时间差很小；全部18主run成功，但不能推断所有条件都稳定。改进的价值依赖问题条件。没有数据支持默认含动量ADOPT、大模型或全部八种方法的排名。

## 可能被问到

**为什么不用默认ADOPT？** 为了与无动量RMSProp聚焦同一个归一化机制，明确采用β₁=0特例；不声称复现默认论文性能。

**为什么两个算法学习率不同？** 公平的是相同候选和选择预算，而不是强制数值相同。数值相同可能只偏袒某一方法；本次仍有搜索边界和100步选参的局限。

**为什么不跑更多步？** 为和Member 4保持共享300调用预算；结果只回答短预算问题。更长训练是后续研究，不是本次已完成的证据。

**能否说ADOPT一定收敛而RMSProp不收敛？** 不能。论文定理依赖假设与步长条件；我们的有限轨迹和实用裁剪设置不是一般证明。

**为什么收敛更快不等于准确率更高？** 训练目标和未见数据质量是不同量。CIFAR ADOPT训练CE更低但测试没有更好，是本次具体例子。

**裁剪是不是全部原因？** 我们增加了相同裁剪但当前二阶矩的控制，仍观察到偏移；也比较了无裁剪ADOPT。这支持本诊断中的时序解释，但不能自动推广到神经网络。

**日志为什么这么快？** 小型网络、小子集、只300调用、CPU4线程，且每次只评估固定前缀；秒数来自真实perf_counter日志。不能拿它对照完整数据集/大模型训练时间。

**你真正需要理解哪几件事？** 两个更新公式、条件期望为什么可能改变、诊断oracle如何无偏、配对实验和测试隔离、每个结果的适用边界。
