# Course requirements summary

This is the team's summary of the course handout, not an official university document.
The original handout remains in the private local course workspace and is not redistributed here.
Check the latest instructor announcements before submission.

- Four team members, each independently implementing at least one relevant algorithm.
- Week 12 topic: Unconstrained Optimization; scheduled presentation: 17 November 2026.
- Report up to 15 pages, including introduction, methodology, experiments/analysis and conclusions.
- Member names and student IDs at the beginning; real GitHub link in the abstract or a footnote.
- NeurIPS 2025 format is encouraged. Keep references/appendices within the 15-page budget unless the instructor clarifies otherwise.
- 30-minute presentation plus 10-minute Q&A; all members participate.
- Combine final report and slides into one PDF under 40 MB, named using the actual group ID.
- Submit through Canvas by 23:59 on the Sunday of the presentation week (22 November 2026 for the current schedule).
- Report 50%: background, formulation/motivation, algorithm design/implementation/theory, experimental analysis, reproducibility (10% each). Presentation 40%; attendance 10%.
- Preserve independent implementation, attribution, reproducible configurations and an accurate README.

The public repository is a scaffold. Experiments and final findings are not complete.
