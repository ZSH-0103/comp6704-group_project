This project investigates when recent modifications of classical optimizers are useful for
unconstrained neural network training under limited computational resources. We plan four
paired comparisons: SGD versus DoG, momentum SGD versus Schedule-Free SGD, RMSProp versus
momentum-free ADOPT, and Adam versus AdEMAMix. A shared protocol uses a small multilayer
perceptron on Fashion-MNIST, a convolutional network on a fixed CIFAR-10 subset, and a
character-level GRU on Tiny Shakespeare. Controlled diagnostics examine step-size adaptation,
training-horizon dependence, second-moment normalization, and gradient-history length.
