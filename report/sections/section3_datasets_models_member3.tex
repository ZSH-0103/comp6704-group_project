\subsection{Datasets and preprocessing}
\owner{Member 3 maintains the shared specification; all members use the same manifest.}
The planned tasks combine two image problems and one sequence problem (Table~\ref{tab:data}).
Official image training data are split into training and validation partitions using saved
indices; official test sets are reserved for final evaluation. The CIFAR-10 training subset
will be stratified and selected only from the training partition. Text is split into contiguous
training, validation and test regions before constructing next-character windows, preventing
windows from crossing split boundaries. Preprocessing is fitted using training data only.

\subsection{Model definitions}
\owner{Member 3; each member verifies the shared model fingerprint.}
Within each task, both optimizers and all four members use the same architecture and loss.
The initial proposal avoids batch normalization and dropout to simplify evaluation-point
handling and reproducibility. Model widths, activation functions, initialization, vocabulary
and parameter counts will be frozen after a short CPU pilot. \fillin{Member 3: replace proposals
